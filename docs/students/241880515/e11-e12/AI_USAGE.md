主要人工核验：Docker 构建和测试退出码、E11/E12 JSON 状态、API 幂等键行为、补丁哈希、SSH health/job 响应及 Git 合并提交。提交前本人需阅读报告并核对实际操作、补充 PR/CI 链接。
